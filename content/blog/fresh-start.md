I've completely rebuilt my personal website with Next.js. Here's why I decided to make the change and what benefits it brings.

## Why rebuild?

My previous site was built with Gatsby but had accumulated some technical debt. The rebuild offers:

1. **Better performance** - Next.js is blazing fast
2. **Improved developer experience** - Latest tools and plugins
3. **Enhanced SEO** - Better metadata handling and image optimization

## The migration process

The migration involved:
- Setting up a new Next.js project
- Configuring components and templates
- Designing the content structure
- Moving blog posts

## What's next?

With this new foundation in place, I'm excited to:
- Add a projects showcase section
- Implement dark mode
- Improve the mobile experience
- Write more consistently

Stay tuned for more updates as I continue to enhance this site!
